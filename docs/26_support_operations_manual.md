# Support Team Operations Manual
**Project**: Enterprise Video Management System (VMS)  
**Owner**: Support Lead  

---

## 1. Support Levels
- **L1 Support**: Check client browser console logs, verify camera power, restart UI pages.
- **L2 Support**: Check systemd service statuses, review active network ports, clean disk spaces.
- **L3 Support**: Audit database indexes, inspect WebRTC signaling SDP handshake payloads.
